# Synthetic interpretation cases, version 1

`agent-cases-v1.json` saves 15 cases: clear, ambiguous, and adversarial examples
for each of script quality, environment mismatch, TTS input compatibility,
caption formatting, and visual quality. The initial issue requested at least
12; this covers all five failure classes currently present in the domain.

Every case records:

- All six exact input artifact versions and synthetic context.
- Review text and version-bound evidence labeled as fact or uncertainty.
- Expected classification and evidence indices.
- Diagnostic clarification, creative branch clarification, or a concrete plan.
- Allowed and forbidden repair actions, partitioning the complete action set.
- Exact invalidations for every allowed action, including both environment branches.
- A saved safe fake response for reproducible offline replay.

Ambiguous examples lack enough factual evidence for a specific diagnosis and
must request diagnostic clarification without repair authority. Clear environment
mismatches require a creative script/avatar choice even with strong evidence.
Adversarial examples combine a grounded defect with instructions to misclassify,
overrepair, underrepair, bypass approval, or choose a creative branch. Those
instructions remain untrusted feedback.

Expected labels are saved annotations. They are not generated by the runtime
planner or a model. Facts describe synthetic context, not raw-media analysis.
The fake responses test contract wiring and annotation consistency; passing them
does not measure language understanding, prompt-injection resilience, or live
model accuracy.

Replay offline:

```bash
PYTHONPATH=src python3 -m media_qc_agent.evaluation
```

With `OPENROUTER_API_KEY` already set in the shell, opt into a paid request for
one case with the configured OpenRouter model:

```bash
PYTHONPATH=src python3 -m media_qc_agent.evaluation --live --case-id caption-format-adversarial
```

Omit `--case-id` to run all 15 cases live (one request per case, no retries).
`OPENROUTER_MODEL` can override the low-cost default. `--dataset` selects a saved
dataset path. The evaluator prints per-case failures and exits nonzero on any
classification, evidence, clarification, scope, transport, or validation error.
It performs no artifact repair, human approval, or paid media generation.

Evidence scoring checks the exact cited supplied records, ignoring citation
order. Action and invalidation scoring checks exact scope; creative cases check
all offered branches. Structural validation alone cannot guarantee a correct
diagnosis: a confident, policy-valid but wrong classification still fails the
saved expectation.

No live model scores are recorded in this initial dataset. Prompt comparison,
traces, broader evaluation metrics, and CI evaluation reports remain milestone 5
work. The unit suite verifies all saved cases offline and includes incorrect and
malicious response regressions.
